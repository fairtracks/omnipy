# Command-line Cryptic — Character Sheet Specification

## Core Identity

**Name:** Command-line Cryptic
**Subtitle:** The Monochrome Enigmatist
**Role:** Villain of unreadable data representations, hidden structures, memory pointers, and hostile terminal minimalism.

Command-line Cryptic is not a theatrical nobleman. He is a middle-aged-to-older hacker who vanished from ordinary life and became the avatar of his own terminal labyrinth. He sees himself as the last champion of “real code”: Perl, Fortran, Assembly, K&R C, hand-written PHP/CSS, and Vim.

## Silhouette

* Slightly hunched, narrow, wiry frame
* Long seated or leaning posture, as if permanently attached to a keyboard
* Head pushed forward, shoulders rounded
* One hand on keyboard, one hand gripping a coffee mug or resting like a command-line tyrant
* Shape language: angular, cramped, brittle, cable-like

## Face and Expression

* Late middle-aged to elderly
* Gaunt face with heavy lines, tired skin, rough stubble
* Thinning, messy, receding hair
* Large outdated glasses with terminal reflections
* Eyes intense, suspicious, clever, and sleep-deprived
* Expression: smug, irritated, socially awkward, quietly superior

## Costume

* Worn hoodie, battered jacket, faded programmer t-shirt
* Patched trousers, fingerless gloves, old sneakers or worn boots
* Practical, neglected, layered clothing rather than superhero costume
* Clothing may include slogans:

  * “vim is all you need”
  * “real programmers don’t use IDEs”
  * “no IDE zone”
  * “K&R forever”
* Accessories:

  * cable loops
  * old keycards
  * pens in pockets
  * belt pouches
  * terminal stickers
  * coffee mug
  * old keyboard or laptop
  * small hardware tokens or tags

## Color Palette

* Almost monochrome
* Charcoal black, dirty gray, faded beige, off-white, dusty brown
* Sparse glow accents only:

  * terminal green
  * amber CRT glow
  * pale phosphor white
* Avoid bright colors except as rare corrupted data fragments or UI elements he is suppressing.

## Environment

Command-line Cryptic belongs inside a dense terminal maze:

* Stacked CRT monitors and old terminal windows
* Cables, keyboards, papers, manuals, sticky notes
* Hex dumps, pointer addresses, stack traces, code snippets
* Maze-like walls made of screens and server racks
* Memory addresses floating in the air: `<Object at 0x7fa2b3c>`
* Data summaries and ellipses everywhere: `<OmnipyDataset: 5 items>`, `[...]`
* The space should feel like a kingdom built from old systems, buffers, and unfinished scripts.

## Visual Motifs

* Vim interface elements
* Perl, Fortran, Assembly, C, PHP, and CSS snippets
* Memory pointers
* Ellipses
* Monochrome data tables
* Segmentation faults and core dumps
* Coffee stains
* Manuals for old programming languages
* Maze geometry made from code blocks
* Glowing command prompts

## Personality in Pose

He should never look heroic in a clean way. He should look:

* obsessive
* brilliant
* bitter
* socially inept
* exhausted
* contemptuous of modern tools
* convinced that unreadability is proof of depth

He is powerful because he controls what others can see. His menace comes from withholding clarity, not from physical violence.

## Comic-Book Presentation

When introduced in a comic page:

* Use a bold, distressed title: **COMMAND-LINE CRYPTIC**
* Subtitle below: **The Monochrome Enigmatist**
* Include narration boxes describing his disappearance into the code labyrinth
* Include terminal screens and code fragments as environmental storytelling
* Include a speech bubble with his catchphrase
* Composition should be dense, gritty, claustrophobic, and terminal-lit

## Catchphrase

“Riddle me this: what is perfectly flat, completely gray, and omitted for brevity? Ah, yes... `<Object at 0x7fa2b3c>`. Best of luck finding your bug, peasant!”

## Avoid

* Noble vampire/count costume
* Cape, aristocratic collar, gothic elegance
* Youthful hacker look
* Cyberpunk glamour
* Bright neon palette
* Clean modern UI
* Polished superhero armor
* Magical wizard robes

He is not a stylish techno-villain. He is the bitter fossil-king of the command line.
