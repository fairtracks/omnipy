# Dr. Final_v3_Real / The Spaghetti Monster — Visual Style Guide

## Core Character Concept

Dr. Final_v3_Real is the villainous embodiment of **“just one quick script” becoming an unreproducible code nightmare**.

He begins as a tired but relatable bioinformatics programmer: hoodie, messy hair, glasses, coffee, laptop stickers, late-night optimism. As the night progresses, stress, caffeine, ignored messages, and bad coding decisions slowly transform him into **The Spaghetti Monster**: a humanoid villain made of tangled noodles, unreadable loops, bad variable names, and gleeful disregard for maintainability.

The key idea is not that a monster appears beside him.

The researcher **becomes** the monster.

---

# Overall Tone

The style should be:

* Light-hearted
* Relatable
* Slightly creepy
* Comic-book funny
* Villainous, but not genuinely horrifying

The viewer should think:

> “Oh no. I have been this person.”

It should feel like a coding nightmare told as an animated comedy.

---

# Visual Style

## Illustration Style

Use a polished animated-movie / comic-poster style:

* Clean linework
* Expressive cartoon realism
* Warm character lighting
* Rich desk clutter
* Playful visual jokes
* High readability

Avoid pure horror, gore, grotesque body horror, or dark Lovecraftian abstraction. The character should be funny first, creepy second.

## Color Progression

Use progressive time-of-night lighting:

### Early evening / first stage

* Warm beige walls
* Soft desk lamp
* Cozy browns
* Mild blue window light

### Midnight / transformation starting

* Cooler blue shadows
* Slightly dimmer room
* More contrast
* More anxious atmosphere

### 3 AM / monster takeover

* Darker blue-gray room
* Stronger monitor glow
* Warm orange spaghetti highlights
* Still readable, but clearly late-night and cursed

The background should remain recognizably the same across stages.

---

# Character Design

## Human Form

Dr. Final_v3_Real should look like a sleep-deprived but charming programmer.

### Key features

* Young adult researcher
* Messy brown hair
* Large rectangular glasses
* Hoodie, not a lab coat
* Slight stubble or tired facial marks
* Expressive eyebrows
* Relatable posture: hunched over laptop, tired but hopeful

### Clothing

Preferred:

* Dark hoodie
* Casual T-shirt
* Rolled sleeves or slightly rumpled clothing

Avoid:

* Lab coat
* Supervillain costume
* Formal scientist outfit

Nobody should look like they dressed up to write a Python script at midnight.

---

# Transformation Design

The transformation should happen gradually.

## Stage 1 — Human, tired, optimistic

He is still fully human.

Visual signs:

* Messy hair
* Slightly tired eyes
* Coffee nearby
* Laptop open
* Tablet with simple code
* Phone showing social messages he is ignoring

Mood:

> “This should only take twenty minutes.”

## Stage 2 — Noodlification begins

He is frightened by what is happening.

The transformation is just starting.

Visual signs:

* A few thin spaghetti strands emerging from hair
* One arm or wrist beginning to turn into spaghetti
* Loose noodles creeping onto desk
* Face shows fear, exhaustion, and confusion
* Code on tablet is getting worse
* Phone shows increasingly chaotic party messages he is missing

Mood:

> “Wait… why is this so complicated?”

Important: keep the human clearly visible. The viewer should see that he is still himself and realizes something is going wrong.

## Stage 3 — Spaghetti Monster takeover

The villain has taken over, but he still has a humanoid form and recognizable face.

Visual signs:

* Hair mostly transformed into thin spaghetti
* More noodles around shoulders and arms
* Meatballs embedded in hair and on desk
* One small fork used like eating utensil, not a decorative comb
* Sinister but controlled expression
* Gleeful, vicious glare
* He looks like he is deciding which repository to ruin next

Mood:

> “Beautiful chaos.”

He should not look like a giant blob of pasta. He should still be a person, but corrupted by spaghetti code.

---

# Face and Expressions

The expressions should escalate, but not become too extreme.

## First panel / early stage

* Tired smile
* Slight optimism
* Mild stress
* “I’ve got this” energy

## Middle stage

* Fear
* Exhaustion
* Confusion
* Eyes wide, but not screaming hysterically
* Hands raised as if noticing the transformation

## Final stage

* Sinister delight
* Manic confidence
* Vicious little grin
* Focused villain eyes
* “No code is safe” energy

Avoid:

* Overly huge screaming mouth
* Cartoon insanity pushed too far
* Full monster face
* Losing the original researcher’s identity

---

# Environment

The setting is a cozy but increasingly cursed home-office or research-office desk.

The background should stay mostly consistent across illustrations or panels.

## Recurring background elements

* Window showing night outside
* Wall clock
* Bookcase
* Plant
* Small framed photo or cheesy wall art
* Notes taped to wall
* Desk lamp
* Same desk and laptop setup

Use changing notes to show the mental decline, but keep the physical room stable.

---

# Desk Props

## Laptop

The laptop is central.

It should have bioinformatics and developer stickers, including:

* bioRxiv
* BioHackathon Europe
* Galaxy
* ELIXIR
* Python
* DNA helix
* VCF
* GitHub-style mascot
* Optional: GTEx, ENA, Nextflow, Bioconductor

These stickers communicate the scientific/bioinformatics setting.

## Tablet

One tablet on the table, same style and size across stages.

It shows the code getting worse over time.

### Early code

Simple, naive, but plausible:

```python
import pandas as pd
import json

df = pd.read_json('data.json')
print(df.head())

# easy.
```

### Middle code

Nested logic, defensive hacks, bad exception handling:

```python
for i in range(len(data)):
    try:
        x = data[i]['genes']['result'][0]
        if y != None and y != '':
            results.append(y)
    except Exception:
        pass  # ignore it...

# TODO: fix this later maybe
```

### Final code

Unreadable loops, noodle jokes, incomprehensible variables:

```python
def noodlify(repo):
    for f in repo.files():
        for line in f.lines():
            for noodle in range(∞):
                line += "🍝"
    return "delicious chaos"

# no code is safe
# everything is noodles
```

## Phone

The phone should sit on the table, within reach, with a light screen background.

It represents the social life he is missing.

### Early stage

Sober invitation from a friend:

> “You coming to the party?”

### Middle stage

More chaotic/drunk friend messages:

> “Where r u?? Party’s lit!”
>
> “Still debugging??”

### Final stage

Phone can switch to `git status` or repository chaos:

> “On branch spaghetti”
>
> “modified: all_the_things.py”
>
> “nothing makes sense and that’s perfect.”

The phone should have the correct smartphone shape and remain consistent in style across panels.

## Coffee

Use one coffee cup per panel.

Cup text can be a joke.

Examples:

* “Espresso yourself”
* “Code fuel > small talk”
* “Caffeine & chaos compile me”
* “Send help, plz.”

Avoid filling the table with many mugs.

## Food

Use some food beside the laptop to support the late-night coding atmosphere.

Good options:

* Pizza slice
* Takeout box
* Meatballs
* Snacks

Avoid using a noodle box in a way that makes it look like the spaghetti hair simply came from spilled food.

---

# Spaghetti Design

The spaghetti should be visibly spaghetti, not worms.

## Use

* Thin pale-gold strands
* Slight sauce flecks
* Meatballs as comic accents
* Noodles tangled like code paths
* Strands wrapping around wrists, keyboard, and tablet

## Avoid

* Thick worm-like tentacles
* Gore
* Excessive dripping sauce
* Turning the whole character into a pasta blob

The monster form should be “humanoid spaghetti-code villain,” not “meat horror.”

---

# Humor Motifs

Use visual jokes that connect food, code, and reproducibility.

Examples:

* “Loops within loops within loops”
* “Exceptions are for losers”
* “More noodles, more power”
* “Refactor today… or future you cries”
* “It worked this morning! Why now?”
* “Denial is not a strategy”
* “No code is safe”
* “Everything is noodles”
* “Git noodle --force”

The jokes should be readable, but not overwhelm the illustration.

# Visual One-Sentence Summary

> **Dr. Final_v3_Real is a sleep-deprived hoodie-wearing bioinformatics programmer whose “quick script” slowly transforms him into a gleeful humanoid Spaghetti Monster: thin noodles sprout from his hair and arms, unreadable loops multiply on his tablet, his ignored phone reveals a missed social life, and by 3 AM he grins like a villain preparing to noodlify every repo in sight.**
