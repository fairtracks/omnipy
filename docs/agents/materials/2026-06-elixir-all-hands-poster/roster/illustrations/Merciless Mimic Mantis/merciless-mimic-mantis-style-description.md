# The Merciless Mimic Mantis — Visual Style Guide

## Core Character Concept

A deceptively harmless guardian that hides in plain sight.

The Merciless Mimic Mantis is not a bulky superhero or an insect monster. She is a **silent observer embedded inside structured data**, appearing harmless until a rule is violated. The visual identity should communicate:

* Camouflage
* Patience
* Intelligence
* Precision
* Sudden violence when constraints are broken

Think:

> A biological ambush predator disguised as a bioinformatics data structure.

Not a warrior standing on a battlefield.

A predator hiding in the dataset itself.

---

# Overall Aesthetic

### Genre

* Sci-fi fantasy
* Bioinformatics-inspired
* Dark technical illustration
* Slightly whimsical
* Character poster art

### Mood

Most of the time:

* Calm
* Observant
* Clever
* Slightly amusing

When activated:

* Fast
* Relentless
* Terrifying

The humor comes from the absurdity of a deadly mantis pretending to be a harmless data object.

---

# Shape Language

### Primary Shapes

* Cubes
* Panels
* Nested blocks
* Folded surfaces
* Brackets
* Rectangles

The character should feel as though she emerged from:

```python
Gene(...)
Sample(...)
Variant(...)
```

rather than from a military factory.

### Secondary Shapes

* Mantis scythes
* Antennae
* Angular wings
* Sharp legs

Avoid:

* Spikes everywhere
* Giant weapons
* Excessive armor
* Overly organic insect anatomy

The silhouette should remain elegant.

---

# Color Palette

### Primary

* Bone white
* Pale ivory
* Light stone

### Secondary

* Emerald green
* Soft neon green

### Accent

* Deep black
* Dark charcoal

### Error Color

Only use bright red for:

* NaN
* Validation failures
* Corrupted data

The red should feel invasive and unnatural compared to the otherwise green palette.

---

# Eyes

One of the most important design features.

### Requirements

* Large
* Glossy
* Almost black
* Highly reflective

The eyes should feel intelligent rather than aggressive.

Like a predator patiently watching.

The eyes should be visible even in camouflage mode.

They are usually the only clue that something is alive.

---

# Camouflage Mode

## Visual Goal

The viewer should initially think:

> "That's a data structure."

Only after a second glance should they notice:

> "Wait... there's a mantis hiding inside it."

### Appearance

The mantis is mostly hidden within stacked blocks.

Visible elements:

* Eyes
* Antennae
* Small portions of forelegs
* Maybe the top of the head

Everything else blends into the structure.

### Data Blocks

Use bioinformatics-oriented examples:

#### Good

```python
Gene(symbol='TP53')

Sample(tissue='liver')

Variant(chrom='17')
```

```python
Sequence(length=502)
```

```python
ExpressionProfile(...)
```

```python
Protein(...)
```

#### Avoid

* Products
* Prices
* Shopping data
* Generic business examples

The blocks should feel like biological metadata.

---

# Enforcement Mode

## Visual Goal

The mantis remains low to the ground.

She should not become a standing superhero.

She is still an ambush predator.

### Pose

Preferred:

* Crouched
* Perched
* Low attack posture
* Sitting while striking

Not:

* Flying
* Standing heroically
* Meditating
* Human superhero stance

### Signature Pose

The mantis remains seated among broken data blocks.

One scythe is extended.

A glowing red:

```text
NaN
```

is being impaled, sliced, or shattered.

This pose perfectly communicates:

* Detection
* Validation
* Rollback
* Enforcement

without requiring explanation.

---

# Wings

The wings should resemble:

* Schema pages
* Data panels
* Model definitions

Not insect wings.

Think:

* Floating documentation
* Folded validation sheets
* Structured metadata panels

They can fan out dramatically during enforcement.

---

# Level of Detail

### Preferred

Medium detail.

Like:

* Animated movie concept art
* Blizzard character illustrations
* League of Legends splash-art simplification

### Avoid

* Hyperrealism
* Excessive mechanical detail
* Dense circuitry
* Thousands of tiny components

The character should remain readable at poster distance.

---

# Backgrounds

### Preferred

Dark.

Examples:

* Black
* Deep green
* Dark digital grid
* Faint floating brackets

The background exists only to support the character.

Never let the environment dominate.

---

# Recurring Visual Motifs

Use repeatedly across all illustrations:

* Nested blocks
* Pydantic model fragments
* Gene and sample metadata
* Green validation glow
* Black reflective eyes
* Hidden observer posture
* Red NaN corruption
* Broken schema fragments
* Floating brackets

---

# Visual One-Sentence Summary

> **A pale emerald mantis with glossy black eyes hides inside stacked bioinformatics Pydantic models like a harmless data structure; when a rule is broken, she remains crouched among the blocks and surgically impales a glowing red NaN with razor-sharp schema-blades.**
